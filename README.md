# 🎓 Student Dashboard

A modern, responsive Student Dashboard built with **React**, **Vite**, and **CSS3** to help students manage their academic information through a clean and user-friendly interface.

---

## ✨ Features

- 📱 Fully Responsive Design
- ⚡ Built with React + Vite
- 🎨 Modern UI with CSS3
- 🧩 Component-Based Architecture
- 👤 Student Profile Section
- 📚 Dashboard Overview
- 📅 Attendance Management
- 📝 Assignments Section
- 📊 Marks & Academic Summary
- 💰 Fee Status
- ⏰ Today's Timetable
- 🔔 Notifications Panel
- ⚡ Quick Action Buttons
- 🌐 Live Deployment using Vercel

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/afzal9798/fatima-student-dashboard.git
```

Go to project folder

```bash
cd fatima-student-dashboard
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open in browser

```text
http://localhost:5173
```

---

# 📦 Production Build

Create production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
