# Student Dashboard

A responsive Student Dashboard web application built using React.js and Vite.

## Features

- Student Profile
- Dashboard
- Attendance
- Marks
- Assignments
- Fee Status
- Timetable
- Notifications
- Responsive Design

## Technologies Used

- React.js
- Vite
- HTML5
- CSS3
- JavaScript
- React Icons
- Git
- GitHub
- Vercel

```bash
npm install
npm run dev
